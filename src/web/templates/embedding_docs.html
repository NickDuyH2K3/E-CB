E-CB Chatbot Embedding Guide

Complete documentation for embedding E-CB chatbots into your website or application

🚀 Quick Start

5-Minute Setup: Get your chatbot running on any website in just a few steps!

Step 1: Get Your Bot ID

First, create a bot in the E-CB dashboard and note your Bot ID. You'll find it in the bot settings.

Step 2: Choose Integration Method

📋 Script Tag (Easiest)

Copy and paste one script tag. Perfect for most websites.

<script async src="https://your-domain.com/cdn/ecb-widget/v2/widget.min.js" data-bot-id="your-bot-id"></script>

🖼️ Iframe (Secure)

Isolated environment with enhanced security. Great for sensitive sites.

<iframe src="https://your-domain.com/v2/bot/your-bot-id/iframe" width="350" height="500"></iframe>

⚛️ React/Vue/Angular

Native components for modern frameworks. Full TypeScript support.

npm install @ecb/react-chatbot-widget

Step 3: Customize (Optional)

Customize colors, position, behavior, and more through the dashboard or configuration options.

Note: Make sure your bot is published and active before embedding!

🔧 Integration Methods

Recommended Script Tag Integration

The easiest way to add a chatbot to any website. Supports all modern browsers and frameworks.

Basic Implementation:

<!-- Place this where you want the chatbot to appear --> <div id="ecb-chatbot-YOUR_BOT_ID"></div> <!-- Load the widget --> <script> window.ECBWidgetConfig = { botId: 'YOUR_BOT_ID', theme: 'modern', primaryColor: '#007bff', embedStyle: 'popup' }; </script> <script async src="https://your-domain.com/cdn/ecb-widget/v2/widget.min.js"></script>

  • ✅ Works on any HTML page

⚙️ Configuration Options

Appearance Settings

Option Type Default Description
theme string 'modern' Widget theme: 'modern', 'classic', 'minimal'
primaryColor string '#007bff' Primary color for buttons and accents
fontFamily string system fonts Font family for widget text
borderRadius string '12px' Border radius for rounded corners

Behavior Settings

Option Type Default Description
embedStyle string 'popup' 'popup', 'inline', 'fullscreen', 'drawer'
autoOpen boolean false Auto-open chat on page load
persistSession boolean true Remember conversation across page reloads
position string 'bottom-right' Widget position for popup style

Feature Toggles

Feature Default Description
enableTypingIndicator true Show typing animation when bot is responding
enableFileUpload false Allow users to upload files
enableEmojis true Support emoji reactions and picker
enableSuggestions true Show quick reply suggestions

🔌 API Reference

Widget Class Methods

new ECBWidget(config)

Creates a new widget instance with the provided configuration.

const widget = new ECBWidget({ botId: 'your-bot-id', theme: 'modern' });

widget.openChat()

Programmatically open the chat widget.

// Open chat when user clicks a button document.getElementById('help-button').onclick = () => { widget.openChat(); };

widget.closeChat()

Programmatically close the chat widget.

widget.clearHistory()

Clear the conversation history and start fresh.

widget.updateConfig(newConfig)

Update widget configuration dynamically.

// Change theme based on user preference widget.updateConfig({ theme: 'dark', primaryColor: '#1f2937' });

widget.destroy()

Remove the widget from the page and clean up resources.

REST API Endpoints

Endpoint Method Description
/api/v2/chat/{botId} POST Send a message to the chatbot
/v2/bot/{botId}/embed-config GET Get widget configuration
/v2/bot/{botId}/embed-code GET Generate embed code
/v2/bot/{botId}/health GET Check bot health status
